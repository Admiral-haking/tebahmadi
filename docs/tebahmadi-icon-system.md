# سیستم آیکون اختصاصی طب احمدی

## هدف

یک خانواده‌ی وکتوری اختصاصی برای فروشگاه طب احمدی که هویت محصولات طبیعی و
گیاهان دارویی را در رابط کاربری، دسته‌بندی‌ها و نقاط اعتماد به‌صورت یکپارچه
نمایش دهد. این سیستم برای استفاده در بنرها طراحی نشده و بنرهای فعلی خارج از
دامنه‌ی آن هستند.

## زبان بصری

- سبک اصلی: خطیِ گیاه‌محور با گوشه‌های نرم، جزئیات کم و خوانایی در اندازه‌ی ۱۶ تا ۴۸ پیکسل.
- سبک دسته‌بندی: همان اسکلت خطی با یک لایه‌ی پررنگِ بسیار کم‌شفافیت برای تشخیص سریع‌تر.
- شبکه: `viewBox="0 0 24 24"`، ضخامت پایه‌ی خط ۱.۷۵ تا ۲، `round` برای cap و join.
- رنگ: آیکون از `currentColor` ارث می‌برد؛ رنگ‌های برند `#2A5A44`، `#1F4635`، `#C5A059` و سطوح کرم استفاده می‌شوند.
- خروجی: SVG بدون فونت، تصویر raster یا وابستگی بیرونی؛ همه‌ی آیکون‌ها باید با رنگ و اندازه‌ی والد سازگار باشند.

## پوشش آیکون‌ها

### دسته‌بندی محصولات

گیاهان دارویی، دمنوش‌های طبیعی، روغن‌های گیاهی، عسل و فرآورده‌ها، عرقیات
سنتی، زعفران و ادویه و یک حالت عمومی برای دسته‌بندی‌های جدید.

### اعتماد و خدمات

ارسال سریع، ضمانت اصالت، پشتیبانی و پرداخت امن.

### اقدامات فروشگاه

خانه، فروشگاه، سبد خرید، حساب کاربری، سفارش‌ها، جست‌وجو، منوی محصولات و وضعیت
اطلاعات هدر.

## قواعد استفاده

- آیکون‌های دسته‌بندی در کارت‌های دسته‌بندی خانه و منوی دسته‌بندی نمایش داده می‌شوند.
- آیکون‌های خدمات در نوار اعتماد نمایش داده می‌شوند.
- اقدامات هدر و حساب کاربری از همین خانواده استفاده می‌کنند؛ آیکون‌های ویرایشگر، پنل مدیریت و رسانه‌های اجتماعی خارج از این بازطراحی هستند.
- ناوبری پایین موبایل نیز از آیکون‌های خانه، فروشگاه، سبد و حساب/سفارش استفاده می‌کند.
- هر آیکون باید عنوان قابل دسترس داشته باشد یا وقتی کنار متن تکراری است با `aria-hidden` رندر شود.
- نسخه‌های ۱۶، ۲۰، ۲۴، ۳۲ و ۴۸ پیکسل باید بدون شکست مسیر یا ازدحام بصری خوانا بمانند.
