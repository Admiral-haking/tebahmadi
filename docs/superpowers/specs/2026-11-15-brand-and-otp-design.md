# طراحی هویت بصری و ورود OTP طب احمدی

## هدف

فروشگاه باید هویت «بسته‌بندی عطاری اصیل با نظم فروشگاه مدرن» داشته باشد: سبز گیاهی `#2A5A44`، زمینهٔ کاغذی `#F9F8F6`، متن زغالی `#222222` و طلایی محدود `#C5A059`. نقش بته‌جقه و قاب اسلیمی از تصاویر تحویلی فقط به‌عنوان هویت برند و تزئین استفاده می‌شوند و جای عکس واقعی محصول را نمی‌گیرند.

## جهت انتخاب‌شده

صفحه مانند برچسب و بسته‌بندی چاپی طب احمدی ساخته می‌شود؛ هدر و hero یک برچسب بزرگ برند هستند، فهرست کالا ابزار خرید باقی می‌ماند و دربارهٔ ما مانند یادداشت برند روی کاغذ خوانده می‌شود. تایپوگرافی فارسی از stack محلی و system استفاده می‌کند و هیچ فونت یا تصویر خارجی برای هستهٔ طراحی بارگذاری نمی‌شود.

## ورود

تمام ورودها فقط از adapter قالب OTP در SMS.ir استفاده می‌کنند. کد به شناسهٔ عددی خاص وابسته نیست؛ شناسهٔ قالب از `SMS_IR_OTP_TEMPLATE_ID` در محیط خصوصی سرور خوانده می‌شود و `SMS_IR_TEMPLATE_ID` فقط برای سازگاری موقت پذیرفته می‌شود. هیچ شناسه‌ای در source، نمونهٔ env یا مستندات ثابت نمی‌شود.

فیلد کد از `autocomplete="one-time-code"` و WebOTP استفاده می‌کند. برای autofill دامنه‌محور، متن قالب SMS.ir باید در انتهای پیام خط استاندارد `@tebahmadi.ir #1234` را پس از جایگزینی پارامترها تولید کند؛ این تغییر در پنل SMS.ir انجام می‌شود، نه در کد سایت.

## قیود

- رفتار cart، checkout، API و نقش‌های کاربری حفظ می‌شود.
- متن نمایشی یا ادعای پزشکی ساختگی اضافه نمی‌شود.
- محصول بدون تصویر، placeholder صادقانهٔ برند می‌بیند؛ تصویر مرجع به‌عنوان محصول نمایش داده نمی‌شود.
- طراحی در عرض‌های 390، 768 و 1440 پیکسل بدون overflow کار می‌کند.
- کلید API و شناسهٔ واقعی قالب در Git یا خروجی تست ثبت نمی‌شوند.
